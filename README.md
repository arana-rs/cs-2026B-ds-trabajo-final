# Trie

Implementación de un árbol trie en C++.

## Requisitos

- `g++` con soporte para C++17
- `make`

## Compilar

```sh
make
```

## Ejecutar

```sh
./main
```

O compilar y ejecutar en un paso:

```sh
make run
```

## Tests

```sh
make test
```

## Benchmarks

```sh
make bench
```

## Limpiar

```sh
make clean
```
